# 软件完成进度

## 已完成

- STM32F446 + FreeRTOS 六任务架构、固定优先级和有界队列。
- IMU 横滚/俯仰二状态 Kalman 滤波，以及气压高度滤波。
- ICM-42688-P、TMP117 原始转换，以及 BMP390 校准系数解析和压力补偿。
- 启动静止校准，能够拒绝陀螺运动、加速度振动和重力大小异常。
- UART DMA 二进制帧、CRC-16、转义、序列号和电脑端解码器。
- 固件端 UART 接收/重同步状态机及分类错误计数器。
- 关键任务健康投票、独立数据可信度监视和低功耗接口。
- 修正 I2C1_TX 与 USART2_TX 的 DMA Stream 6 冲突；I2C1_TX 改用 Stream 7。
- Python 协议测试 10/10 通过；便携 C 模块通过 ARM GCC 严格编译检查。
- 实时 CPU/栈预算和硬件 WCET 测量方法。

## 在没有实物板时仍未能验证

- ICM-42688-P 的 SPI DMA 完成中断与真实数据就绪时序。
- BMP390 补偿参数的总线读取以及真实压力精度。
- TMP117、BMP390 共用 I2C 总线时的超时恢复。
- STOP 模式唤醒后的系统时钟恢复、实际功耗和 IWDG 复位。

这些项目不是电脑模拟能够证明的，必须在接线完成后用调试器、串口和逻辑分析仪验证。

## 本机重复验证

在项目目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File tools\verify.ps1
```

脚本会自动使用 `C:\ST` 里的 STM32 ARM GCC，不会联网或安装软件。
